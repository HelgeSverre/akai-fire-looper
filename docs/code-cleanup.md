### Extended transition table

| From | Event / guard | Owner and effect | To / failure behavior |
| --- | --- | --- | --- |
| App initialized | run(duration≥0 finite), FPS>0 | Base marks running; optional banner, on_start, polling, monotonic deadline | running; finally shutdown even on hook failure |
| Running | duration, quit, window close, Ctrl+C | Base removes callbacks, calls on_stop once, closes owned controller | terminal; borrowed controller retained |
| Circuit stopped | PLAY or REC | Transport lock serializes start/stop; musical clock starts | playing/recording |
| Circuit any transport | STOP | Under state lock: STOPPED, clear scheduled/version/active state, send all-off; release state lock before joining clock | stopped; pending callback rechecks STOPPED |
| Note scheduled | deadline due, matching version | Scheduler sends under shared state lock; note-off updates active state | active/off; retired versions skipped |
| Synth unknown/local value | knob or pad | Send documented CC then commit local value | local value; startup sends none |
| Synth snapshot | load, whole payload valid | Validate profile/CC keys/int range before any send | local values updated per successful send; malformed file sends nothing |
| Synth audition | deadline, STOP, channel change, shutdown | Instrument owner sends off on original channel; close releases port in finally | silent/closed; disconnected send may fail |
| Scope live | input | Append bounded history, counts, trace | live; frozen input ignored except controls |
